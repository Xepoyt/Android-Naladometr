# Náladometr
Aplikace umožňuje zapisovat si svou náladu na škále od 0 do 10 a případně k zápisu přidat poznámku. Můžete tak během dne sledovat, jak reagujete na běžné i nečekané události. Ke štěstí se přibližuje snáz, když víte, co mu brání. Stránka analýzy vám usnadní vypozorování vzorů pomocí zprůměrování nálad za každý den. 

## Obsluha aplikace
Obsluha aplikace je jednoduchá: Na posuvníku vyberete svou současnou náladu a poznámku si napíšete do textového pole. Pak už stačí stisknout tlačítko „Uložit“. Pomocí menu se dostanete na stránku výpisu, kde můžete jednotlivě vidět každý zápis, nebo na stránku analýzy, kde jsou nálady za každý den zprůměrovány.
